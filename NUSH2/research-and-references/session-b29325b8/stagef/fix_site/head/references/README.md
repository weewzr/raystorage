# References

Every work cited by the engine (`engine/data/parameters.toml`), the results files, the derivations (`math/refs.bib`), the report and the documents in `docs/`. Each entry gives a DOI or a URL where one exists and was checked; an entry with neither says so. No paper is stored in this repository.

DOIs come from `math/refs.bib`, read from the header of each local PDF, or from a Crossref record whose journal, volume and first page match the citation. A URL marked "returned 404" was dead when it was checked on 2 November 2026, and the report number is kept as the identifier.

SMR in a title means steam methane reforming. Where a source title uses the abbreviation for a small modular reactor, the term is written out in square brackets.
