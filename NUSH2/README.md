# NUSH2 working files

Text-type working files from the NUS-H2 modelling sessions (notes, scripts, JSON and CSV exports, logs, diagrams), kept so the work can be resumed. The product repository is separate.

Layout: `NUSH2/<category>/<origin>/<relative path in the original working folder>`. Categories: derivations, simulations, process-data, PFD-versions, research-and-references, validation. `MANIFEST.csv` lists every file with its size and SHA-256.

Left out on purpose: build caches, virtual environments, images and video frames, copies of downloaded papers and documents, text extracted from them, OUTRAM code (AGPL), and every file that matched the privacy scan (names, identifiers, course or group text, keys or passwords). Files with identical content are stored once.
